### 1. **Programa/Python Script para migración automática**
**Objetivo:** Automatizar el proceso de copiar registros de Israel a Miguel sin intervención humana.

**Código base (ejemplo):**
```python
import pandas as pd

# Ruta de archivos (personalizable)
ruta_israel = "/Documentos/Operaciones/Israel_2026-07-17.csv"
ruta_miguel_final = "/Documentos/Reportes/Miguel_Consolidado_2026-07-17.csv"

# Cargar archivo Israel
israel_df = pd.read_csv(ruta_israel)

# Crear archivo destino Miguel (copiando estructura con validación)
miguel_final_df = israel_df.copy()

# Agregar lógica de validación automática:
if list(israel_df["Cajas_Woodfarm"].isna().values):
    miguel_final_df["Cajas_Woodfarm"] = israel_df["Totales_Racimos"] * 0.12  # Ejemplo: asignar 12% a Woodfarm

# Exportar archivo automático
miguel_final_df.to_csv(ruta_miguel_final, index=False)

print("✅ Validación y migración automática completada. Archivo generado:", ruta_miguel_final)
```

**Beneficio:**
- **Elimina errores manuales** en Miguel (Benjamin no necesita procesar).
- **Reduce tiempo** desde 30 min (manual) a 2 min (automático).
- **Garantiza consistencia** con los datos de Israel.
