# 🧠 NeuroDesign Engine · Framework de Neuromarketing Visual & Saliencia Cognitiva

Este skill confiere a Antigravity y Alberth la capacidad de operar como un **Laboratorio de Neurociencia del Consumidor, Biometría Visual y NeuroDesign Computacional**.

---

## 1. Fundamentos Científicos del NeuroDesign

Toda pieza publicitaria (anuncio estático, portada de video, cartel físico o landing page) es procesada por el cerebro humano en dos etapas:
1. **Fase Preatentiva (0 - 50 milisegundos)**: El cerebro reptiliano y el tálamo visual filtran la escena. Si no hay contraste, rostros o saliencia, el estímulo es descartado antes de llegar a la consciencia.
2. **Fase Atentiva (50 - 1500 milisegundos)**: El lóbulo frontal intenta descifrar el significado. Si la carga cognitiva es alta o hay texto ilegible, el usuario hace scroll o aparta la mirada.

## 2. Los 6 Pilares del NeuroDesign Publicitario

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           NEURODESIGN ENGINE                                │
├──────────────────────┬──────────────────────┬───────────────────────────────┤
│ 1. SALIENCIA CROMÁTICA│ 2. REGLA FFA (FACES) │ 3. PATRÓN DE ESCANEO F & Z    │
│ • Contraste Von Rest.│ • Neuronas espejo    │ • Puntos focales naturales    │
│ • Delta E > 3.0      │ • Mirada dirigida    │ • Zona caliente: arriba/izq   │
├──────────────────────┼──────────────────────┼───────────────────────────────┤
│ 4. THUMB-STOP RATE   │ 5. CARGA COGNITIVA   │ 6. GATILLO DOPAMINÉRGICO      │
│ • Quiebre de patrón  │ • Regla de 2 focos   │ • Recompensa inmediata (Hook) │
│ • 3 segundos de oro  │ • Ley de Hick        │ • Micro-CTA sin fricción      │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Pilar 1: Saliencia Cromática y Efecto Von Restorff
* **Efecto de Aislamiento**: El cerebro solo recuerda el elemento que rompe la monotonía del fondo.
* Si el anuncio tiene fondo oscuro (`#070B14`), el elemento de conversión (botón, precio o teléfono) debe tener una luminancia polarizada (ej. Verde Esmeralda `#10B981` o Ámbar `#F59E0B`).
* La relación de contraste mínima para el Call To Action (CTA) debe ser **WCAG AAA (> 7:1)**.

### Pilar 2: Regla FFA (Fusiform Face Area & Mirada Dirigida)
* El cerebro humano tiene un procesador dedicado exclusivamente a rostros (el área fusiforme facial).
* **Dirección de la Mirada (Gaze Cuing)**: Cuando colocamos una persona en el anuncio:
  - ❌ **Mirando a la cámara**: El usuario se queda viendo los ojos del modelo y NUNCA lee el texto ni el botón.
  - ✅ **Mirando hacia el titular o el botón**: Activa las neuronas espejo del observador, forzando al ojo del cliente a deslizarse exactamente hacia el mensaje o el CTA.

### Pilar 3: Patrón de Escaneo Ocular (F & Z Patterns)
* En anuncios cuadrados (1:1) o verticales (9:16):
  * **Punto Caliente 1 (Superior Izquierdo / Centro)**: Gancho visual o titular de alto impacto (romper el patrón).
  * **Punto Caliente 2 (Centro)**: Demostración visual del producto / dolor resuelto.
  * **Punto Caliente 3 (Inferior Centro / Derecho)**: Botón de acción (WhatsApp, Descarga, Compra) con micro-texto de seguridad ("Pago en Efectivo", "Sin Tarjetas").

### Pilar 4: Arquitectura Thumb-Stop (> 35%)
Para redes sociales (Instagram, TikTok, Facebook):
* Los primeros **3 segundos o el primer scroll** deciden el costo del anuncio. Si el usuario no se detiene, el algoritmo de Meta/TikTok penaliza el anuncio subiendo el CPM.
* Elementos obligatorios para detener el pulgar:
  1. *Visual Pattern Interrupt*: Un objeto fuera de lugar, movimiento inesperado o texto de alta curiosidad.
  2. *Titular con Aversión a la Pérdida*: "El error que te cuesta $X" supera 3x a "Cómo ahorrar $X".

### Pilar 5: Reducción de Carga Cognitiva (Ley de Hick)
* El cerebro reptiliano es perezoso y ahorra glucosa. 
* Si un anuncio contiene más de 7 palabras en el titular o más de 2 llamadas a la acción distintas, la tasa de conversión cae un 60%.
* **La Regla de los 2 Segundos**: Si una persona no entiende de qué se trata el servicio en 2 segundos a 5 metros de distancia o con la imagen desenfocada (*Blur Test*), el diseño ha fracasado.

## 3. Matriz de Auditoría NeuroDesign (Checklist 0 a 100)

Al auditar o diseñar cualquier creativo, se califica sobre 100 puntos:

| Criterio NeuroDesign | Puntos | Verificación |
| :--- | :---: | :--- |
| **Poder de Gancho (Thumb-Stop)** | 25 pts | ¿Tiene un elemento visual disruptivo en los primeros 200ms? |
| **Jerarquía y Escaneo F/Z** | 20 pts | ¿La vista fluye naturalmente del gancho al beneficio y luego al CTA? |
| **Saliencia y Contraste CTA** | 20 pts | ¿El botón o llamada a la acción es el elemento más contrastante? |
| **Dirección de Mirada (FFA)** | 15 pts | Si hay rostros/vectores, ¿apuntan hacia el texto clave? |
| **Claridad Cognitiva (Blur Test)** | 10 pts | ¿Se entiende el mensaje principal si entrecierras los ojos? |
| **Gatillo de Aversión/Seguridad** | 10 pts | ¿Elimina el miedo primario (ej. "100% Efectivo", "Validado ANT")? |
| **TOTAL** | **100 pts** | **Aprobado: ≥ 85 pts** |

---

## 4. Protocolo de Ejecución
Siempre que se pida evaluar, criticar o crear una pieza visual o publicitaria:
1. Someter la pieza al **Checklist de Auditoría NeuroDesign**.
2. Identificar el área de fuga de atención visual.
3. Proponer los ajustes cromáticos, tipográficos y de encuadre basados en neurociencia para elevar el Thumb-Stop Rate y la conversión final.
