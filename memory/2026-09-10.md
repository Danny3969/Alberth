### 5. Agente Autónomo de Navegación Web con Playwright (`alberth_playwright_agent.py`)
- **Objetivo:** Dotar a Alberth de una solución agéntica equivalente a **Browser-Use**, basada en **Playwright** nativo sobre Python 3.9 sin romper el entorno virtual del sistema y con navegación en segundo plano (`Headless`).
- **Capacidades Implementadas:**
  1. **Navegación Silenciosa en Segundo Plano (`Headless`):**
     - Controla un navegador Chromium real sin abrir ventanas ni mover el ratón físico de la Mac del Señor Danny.
     - Incluye modo visual `--headed` para supervisión en vivo si el usuario lo desea.
  2. **Indexación Determinista del DOM (`data-alberth-id`):**
     - Inyección en la página de un script JS que detecta elementos interactivos visibles (enlaces, botones, campos de texto, selectores) y les asigna un identificador numérico único `[1], [2], [3]...`.
     - Permite que el LLM emita acciones exactas por ID (`click(2)`, `fill(3, 'texto')`, `goto`, `press`, `scroll`, `finish`), evitando errores por resolución de pantalla o clics perdidos.

     - Observación del estado actual de la página -> Decisión del LLM (Qwen 2.5 Coder / DeepSeek / Gemini) -> Ejecución Playwright -> Extracción de párrafos estructurados para el Señor Danny.

### 6. Arquitectura Híbrida de Síntesis de Voz SOTA (`alberth_tts_premium.py`)
- **Evaluación Estratégica Kokoro-82M vs Edge-TTS:**
  - Se analizó el modelo open-source Kokoro-82M. Aunque es popular para idioma inglés (80 MB), su soporte de español es secundario/experimental (acento anglosajón y entonación más mecánica), y su paquete `kokoro-onnx` genera incompatibilidades de dependencias en Python 3.9 al requerir versiones específicas de ONNX Runtime no compiladas para este entorno.
  - Las voces neuronales de Microsoft Edge-TTS (`es-MX-JorgeNeural`, `es-CO-GonzaloNeural`, `es-ES-AlvaroNeural`) ofrecen una calidad infinitamente superior, naturalidad humana en español, cero consumo de CPU/GPU y costo $0.00.
- **Implementación del Fallback Automático Offline:**
  - Para garantizar que Alberth nunca quede mudo si se corta la conexión a internet, se implementó una **Arquitectura Híbrida** en `alberth_tts_premium.py`:
    1. **Ruta 1 (Primaria - Online):** Edge-TTS con voz `es-MX-JorgeNeural` (modulación SSML `-8%` velocidad y `-3Hz` de tono más grave) a 0% de CPU local.
    2. **Ruta 2 (Fallback Automático - Offline):** Motor nativo de macOS (`/usr/bin/say`) con voz en español (`Paulina` / `Mónica` / `Eddy`) y codificación directa a MP3 con `ffmpeg` / `afconvert`.
- **Pruebas Validadas:**
  - Generación online con Edge-TTS validada (27 KB MP3 en < 0.8s).
  - Generación offline sin internet simulada con macOS 'Paulina' validada (35 KB MP3 en < 0.2s).
