### 1. Módulo Orquestador de Modelos Fundacionales (`alberth_foundation_models.py`)
- **Objetivo:** Dotar a Alberth de una arquitectura multi-modelo inteligente que asigna cada consulta al modelo fundacional abierto de mayor reconocimiento y prestigio mundial según su rol.
- **Especialización por Roles:**
  1. **🧠 DEEPSEEK (R1 / V3 / V4 Pro):**
     - **Rol:** `ROLE_REASONING`
     - **Capacidades:** Razonamiento matemático, deducción lógica paso a paso, resolución de problemas abstractos, análisis de hipótesis y planificación arquitectónica.
     - **Enrutamiento:** Conexión prioritaria local a Ollama (`deepseek-r1:latest`), Fast-Path a NVIDIA NIM (`deepseek-ai/deepseek-v4-pro-0813`), soporte nativo a DeepSeek API oficial y fallback a Gemini 2.5 Flash en modo razonamiento.
     - **Benchmark validado:** Deducción de tiempo de viaje de tren resuelta con precisión en 2.35s ("Señor Danny, el tren llega a las 16:30").
  2. **💻 QWEN 2.5 CODER (Alibaba):**
     - **Rol:** `ROLE_CODING`
     - **Capacidades:** Generación de código limpio, refactorización, depuración de bugs, scripts Bash/Python para macOS, consultas SQL y llamadas a APIs de sistema.
     - **Enrutamiento:** Conexión prioritaria local a Ollama (`qwen2.5-coder:latest`), Fast-Path de ingeniería de software en NVIDIA NIM (`meta/llama-3.2-11b-vision-instruct` especializado en código) y fallback a Gemini 2.5 Flash Code.
     - **Benchmark validado:** Generación de función de validación de archivos en macOS validada.
  3. **👁️ META LLAMA 3.3 (70B) / 3.2 VISION:**
     - **Rol:** `ROLE_VISION_FAST` & `ROLE_GENERAL`
     - **Capacidades:** Visión multimodal en tiempo real (cámara web FaceTime HD, capturas de pantalla) y conversación ágil.
     - **Enrutamiento:** Conexión ultrarrápida a NVIDIA NIM (`meta/llama-3.2-11b-vision-instruct`, 1.13s - 1.97s) con fallback a Gemini 2.5 Flash multimodal y Ollama local.
     - **Benchmark validado:** Presentación y conversación fluida en 1.13s - 1.97s.
