- **Symlink & Alias:** `~/alberth_cli` vinculado al proyecto, alias `agc` y autocompletado cargados en `~/.zshrc`.

### 2.2 Backend FastAPI (`alberth_web_server.py`)
- **`POST /api/console/event`:** Recibe eventos de ejecución y los emite en tiempo real vía WebSocket `manager.broadcast({"type": "console_event", ...})`.
- **`GET /api/console/logs`:** Historial en memoria de los últimos 60 comandos ejecutados.
- **`POST /api/console/exec`:** Ejecuta comandos de consola directamente solicitados desde la interfaz web del HUD.
- **WebSocket `/ws`:** Soporte para eventos de tipo `console_cmd` y `console_event`.

### 2.3 Frontend Quantum HUD (`panel/index.html`)
- **Botón en Navbar:** `[ 💻 AGC Dev ]` con indicador de estado activo.
- **Drawer Deslizante (`#dev-console-drawer`):**
  - Barra superior de proyectos para filtrar y alternar entre `TODOS`, `DRIVO`, `DRIVO ONE`, `ALBERTH`, `GLOBALMARKET` y `VALEX`.
  - Botonera táctica de 1 clic:
    - `[ 🚀 Abrir Antigravity ]`
    - `[ 🌿 Git Status ]`
    - `[ ⬇️ Git Pull ]`
    - `[ ⚙️ PM2 ]`
    - `[ 📋 Proyectos ]`
  - Terminal en vivo con estilo Cyber-HUD, scanlines, badges (`SUCCESS`, `ERROR`, `RUNNING`) y autoscroll.
  - Barra de entrada de comandos web con ejecución directa.
  - Botones de utilidad: **Limpiar terminal** y **Copiar logs**.
- **Atajo Global de Teclado:** `Ctrl + Alt + C` (o `Cmd + Alt + C`) alterna la consola desde cualquier parte de la pantalla.
