## 3. Diagnóstico y Auditoría Web del Proyecto DRIVO

### 3.1 Claridad Absoluta del Core Service de DRIVO
- **Propósito Principal:** Plataforma de transporte urbano de pasajeros tipo Uber/InDrive desarrollada por Novasyscom.
- **Diferenciadores Técnicos:**
  - Negociación y contraoferta de precios en tiempo real (bidding/pujas) entre pasajero y conductor.
  - Radar en vivo y seguimiento de vehículos sobre Google Maps SDK.
  - Modelo de comisión baja y transparente (10% debitado del `walletBalance` prepagado del conductor).
  - Verificación de seguridad (placas, cooperativas de transporte y cédula).
- **Distinción Crítica con DRIVO ONE:**
  - **DRIVO:** Transporte urbano de pasajeros (1 app unificada Flutter, backend Firebase Cloud Functions + Firestore).
  - **DRIVO ONE:** Delivery y comercio multitienda (3 apps móviles separadas para cliente, conductor y comerciante, backend Express + PostgreSQL/Prisma).

### 3.2 Auditoría de Presencia Web
- **Resultado:** **NO existe página web pública ni landing page oficial construida para DRIVO**.
- **Activos Actuales:** El único componente web existente es `macondo-admin-web/` (panel administrativo privado en Flutter Web para gestión interna de conductores, viajes y flotas).
- **Conclusión:** Se requiere construir desde cero la **Landing Page Oficial Pública de DRIVO**, diseñada para captación de pasajeros, reclutamiento de conductores y descarga de la aplicación móvil.
